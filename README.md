
# Logistics WMS Demo (Frontend-only)

This is a frontend-only prototype of a Logistics & Supply Chain Warehouse Management System. It demonstrates a modern enterprise UI for dashboards, orders, warehouse and transportation management using hard-coded mock data.

Quick start:

```bash
cd /home/sam/Documents/Advanced_Software
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

Files of interest:

- `src/` — application source
- `src/data/` — mock data files (orders, shipments, inventory, vehicles, suppliers)
- `src/components/` — reusable UI components
- `src/pages/` — route pages

Notes:

- This is a frontend demo only — there is no backend, database, authentication, or external API integration.
- A `.gitignore` has been added to exclude `node_modules`, build output, and local env files.
- The AI Assistant page is a visual demo and does not call any LLM.

Logistics & Supply Chain Management System
Overview

The Logistics & Supply Chain Management System is an application designed to manage and monitor the movement of products from suppliers through warehouses to customers.

The system provides a central platform for managing inventory, suppliers, warehouses, orders, shipments, and deliveries. Its main goal is to improve supply chain visibility, reduce manual work, prevent inventory shortages, and make logistics operations easier to manage.
